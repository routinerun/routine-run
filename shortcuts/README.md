# Shortcuts

A step in Routine Run can run a shortcut by its exact name. A model asked to write a routine
reaches for a likely name — "Focus" — and for almost everybody there is no such shortcut,
so the step does nothing. These are names that are always right: the shortcuts Routine Run
publishes, each with a link that adds it in one tap.

[`ours/`](ours) — one file each: the name, the iCloud link, what it does, and what it takes
as input. Every name ends " via Routine Run", so a call by name can never reach a shortcut
of your own that happens to be called the same.

They are only for what a step cannot do by itself — Focus, Low Power, the radios, volume and
brightness, music, a Clock timer. A shortcut for anything a step already does is one more
thing to install for nothing.

A shortcut is somebody's code on your phone. Before adding one, the sheet Shortcuts shows
you lists what it does; read it.

Shortcuts other people write will go in `community/`, reviewed against what Apple's own
record of each says it does. Until then, [suggest one](https://github.com/routinerun/routine-run/issues/new?template=shortcut.yml).
