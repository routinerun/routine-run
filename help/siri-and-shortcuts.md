# Siri and the Shortcuts app

Everything below also works as an action in the Shortcuts app, under Routine Run.

The phrases, with a morning that uses them, are on [the Siri page](https://routinerun.com/siri).

## Say it to Siri

Say the name of your routine where it says *Morning*. On the phone Siri forgives near
misses; on the watch, say it exactly as written.

| To | On the phone | On the watch |
|---|---|---|
| Start a routine | "Routine Run me", "Routine Run me through Morning", "Start a routine in Routine Run", "Run Morning in Routine Run", "Routine Run start Morning" | "Routine Run me through Morning", "Start Morning in Routine Run" |
| Move to the next step | "Next step in Routine Run", "Routine Run next step" | "Next step in Routine Run" |
| Hear the step you are on | — | "Routine Run current step" |
| Put the step off | "Put this step off in Routine Run", "Routine Run not this step", "Skip this for now in Routine Run" | — |
| Write a note on the step | "Write it down in Routine Run", "Note this in Routine Run", "Routine Run write this down", "Take a note in Routine Run" | "Note this in Routine Run" |
| Add a step to a routine that stays open, like To read | "Add to To read in Routine Run", "Routine Run add to To read", "Add a step in Routine Run" | — |
| Have a routine written from a sentence | "Write a routine in Routine Run", "Routine Run write me a routine", "Make a routine in Routine Run" | — |
| Hear what is coming today | "What's coming in Routine Run", "Routine Run what's coming", "What have I got in Routine Run" | — |
| Hear where you are and what to press next, then see what is in hand | "What do I do here in Routine Run", "Help me in Routine Run", "Routine Run in hand", "What's in hand in Routine Run", "Show me Routine Run" | — |
| Stop the routine going | "Stop my routine in Routine Run", "Routine Run stop my routine" | — |
| Press the one thing, as the Action button does | "Do the one thing in Routine Run", "Routine Run do the one thing", "Routine Run one thing" | "Routine Run one thing" |

Apple allows an app ten phrases, and these are the ten. More than fifty other actions have
no phrase of their own: they are in the Shortcuts app under Routine Run, and a shortcut you
make from one can be given any phrase you like.

What Siri writes or changes is kept at once, because nobody is looking at a page. Every
change keeps the earlier version: **Undo Change to a Routine** puts it back, and so does
the undo bar in the app.

## "What do I do here?"

Siri can read the screen but not what the app means by it, so Routine Run answers this
itself. Asked on a run's page, it says the step you are on and what to press; on a step,
what on it waits for you to allow it or for a secret; anywhere, what a run holds
unanswered — and then shows what is in hand. With the app closed, it says what is going.

It needs no Apple Intelligence: the answer comes from the run itself. In the Shortcuts
app, **What To Do Here** also takes a question of your own, which Apple's model answers
about the screen you are on, where a model is available.

## Open the app at a routine or a run

**Open Routine Run**, in the Shortcuts app, takes a screen, a routine or a run, and a
routine or run can be given by its name: a shortcut, a widget or a button can open the app
straight on "Morning".

## Actions that change routines

| Action | Does |
|---|---|
| Write a Routine | Writes a routine from a sentence, or reads an assistant's answer |
| Change a Routine | Applies an assistant's answer to a routine that exists |
| Rename a Routine | Renames it |
| Add a Step to a Routine | Adds a step, at the end or after another |
| Change a Step | Renames it, or changes its length or description |
| Remove a Step | Takes it out (not the last one) |
| Move a Step | Moves it up or down |
| Add an Action to a Step | A link, a shortcut (and what to hand it), words to say, a webhook or a Home scene. A webhook or a scene waits for Allow on the step's page |
| Undo Change to a Routine | Puts back the version before the last change |
| Change a Step in a Run | Changes a step for this run only. Without a step, the one you are on |
| Keep What a Run Collected | Answers Keep or Only here for a run or one of its steps |

For writing prompts yourself: **Prompt for a Routine** and **Prompt to Change a
Routine** give the same request the app sends, to hand to any model.

## "Ask Siri" in a menu

On iOS 27, holding a routine or a run shows **Ask Siri**. Siri is handed that routine or
run as text: its steps, notes and where it stands. Ask about it in your own words.

Siri does not yet change a routine from there by itself. To change one in words, use
**Describe changes…** in the app, or run the actions above from the Shortcuts app.

## The actions the shortcut uses

**Get the Question**, **Which Model** and **Bring the Answer** exist for the
[Routine Run Ask shortcut](the-ask-shortcut.md). You do not need them on their own.
