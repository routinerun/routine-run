# Routines, runs and steps

A routine is the list, written once. A run is one time through it. Steps are the items on the list. A run reads its steps from its routine, and anything you change during a run belongs to that run until you say otherwise.

## Three shapes

The same marks appear everywhere, from lists to the Lock Screen and the watch.

| Mark | What it is |
|---|---|
| Rounded square | A routine. It can be started. |
| Ring | A run under way. The ring fills as it goes. |
| Plain disc | A run that has stopped, finished or not. |

## Which page you are on

A routine and each of its steps has a page, and so does a run and each of its steps. Every page says what it is, in bold, under its name: **Routine**, **Run** or **Step**. A step's page says whose step it is on the row directly below, with that routine's or that run's own mark. Tap the name to see what the marks beside it mean.

- **A run's page** opens with the step in hand and its buttons, and under them every step it is walking. Between the two is the run's own card: its mark, its name, what it is about, and two corners — **Add or see…** for everything this run holds of its own, and the gear for how it is set up. A routine's page is built the same way. An orange dot on a corner means something behind it is still this run's alone.
- **A step's page** has no buttons. It says where the step stands, such as In hand, Done or Still to come, and whether the run is waiting on it. The row under that opens the run, or the routine, with this step's card showing. **Next**, **Again** and **Not now…** are on that card.
- **Press and hold** any routine, run, step or Settings row to see what it holds before opening it.

## Where they live

The Routines tab has three halves. **Routines** is what you have written down. **Runs** is what is going, planned or finished. **Steps** is every step of every going run in one list.

## A run follows its routine

- **Change the routine, and runs going now follow.**
- **Change a step inside a run, and only that run changes.** A new name, a different length, a note or a value written there belongs to this run. It is marked orange and counted by the band at the top. See [Keep or Only here](keep-or-only-here.md). A value the step's name quotes is different: it is filled in where the name is shown, and changes nothing about the step. See [Values in a step's name](values-in-a-step.md).
- **A run can have steps of its own.** The plus on the run's page, then **Step**, adds one **Now**, **Next** or **Last**.
- **A finished run keeps the routine it read.** Delete the routine later, and old runs still show their steps. **Again** on one of them brings the routine back.

## One at a time, or several

A routine runs one at a time unless you say otherwise. Pressing **Start** while a run of it is going offers:

- **Start it again**, which ends the run that is going and starts a new one.
- **Add another one alongside**, which keeps both. The routine runs several at a time from then on.
- **Plan it for later…**, for a day and a time.

The routine's **Settings** has **Allow several at once**.

## A run with no routine

The plus in the middle of the tab bar, then **Something new…**, starts a run from just a name. Add steps as you go. At the end the band asks one question: whether it was worth keeping. **Keep it as a routine…** turns the run into a routine.

## When something goes wrong

- **A run shows the old wording after you edited the routine.** That step was changed in the run itself, and the run's own version wins. Keep it, or change it back.
- **Old runs still show a routine you deleted.** On purpose: a run is the record. See [Recently Deleted](recently-deleted.md).
- **Start it again ended a run you were in.** It went to Cancelled with everything it collected. Find it under **Runs** and press **Reopen**.
