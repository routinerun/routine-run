# Actions in Shortcuts: running routines

Search for Routine Run in the Shortcuts app and you get actions that start routines and move runs along, for a shortcut, an automation or the Action button. None asks for Face ID, so they work on a locked phone.

## Which run an action means

Most actions have a **Run** field. Left empty, the action works on the run you started most recently, paused or not. A run planned for later does not count. Fill the field in when you have several going.

## Starting and moving

| Action | Does |
|---|---|
| Start Routine | Starts a routine, with a name or description if you give one |
| Plan a Run | Makes a run for a moment ahead, which begins by itself |
| Start the Planned Run | Begins a planned run now |
| Do It Again | Starts the routine a run was of again, from the first step |
| Next Step | Moves to the next step. If the step is not finished, it says why and stays |
| Repeat | Goes round the step you are on again: its actions run and its timer starts over. Not on a paused run |
| Put the Step Off | Moves the step later, or last |
| Decide Later | Sends the step to the end of the run and puts a question about it in In hand |
| Pause the Run, Resume the Run | Pauses the run where it stands, or picks it up again |
| Come Back To It | Puts the run down for some minutes, then brings it back |
| Not Any More | Brings a put-down run back now |
| Stop | Ends the run. Everything it recorded is kept |
| Control Routine | Any of these for a routine's going run, chosen from a list |

## The step's own buttons

| Action | Does |
|---|---|
| Do the One Thing | What the [Action button](action-button.md) does |
| Run a Step's Action | Opens a link or shortcut the step is waiting on |
| Do What a Step Is Holding | Does an action the step holds until somebody asks |

## Asking and writing down

| Action | Does |
|---|---|
| Current Step | Says what the run is on and how far through it is |
| What's Coming | Says what is going, what is coming, and what you put down |
| Show What Is In Hand | Shows the In hand panel over the screen |
| Write It Down | Keeps a note on a run, at its step |
| Tag | Puts a tag on a run or a routine, or takes one off |
| Set Value, Get Value | Writes or reads a value on a run, a step or a routine |
| Open Routine Run | Opens the app at a screen or a run |

The actions that write and change routines are on [Siri and the Shortcuts app](siri-and-shortcuts.md).

Every action here works on iOS 26. **Needs iOS 27.** A Shortcuts automation that starts when a notification arrives, which is how the bridge runs a step's shortcuts by itself. See [Answers in the background](in-the-background.md).

## When it goes wrong

**"Nothing is running."** No run is going, or the only one is planned for later.

**It moved the wrong run.** The empty field took the newest. Choose the run in the action.
