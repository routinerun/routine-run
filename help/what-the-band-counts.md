# What does the orange band count?

The orange band at the top of a run, such as "3 things go when this run does", counts what this run holds of its own that nobody has answered yet. It is one number for the whole run, the same on every page of it and on its row in a list. **Review** opens the one screen that can bring it to nought.

![A step made longer for this run, and the band counting it.](band)

## What it counts

| Counted | For example |
|---|---|
| A value or a note, on the run or one of its steps | A reading typed into a step |
| A step the run added itself | A step added with the run's plus |
| A step changed for this run | A new name, mark, length or count, or an action added or removed |
| A trigger or a reaction the run added | A reminder at six, on this run only |
| The run's own settings | Its own Lock Screen buttons, or what it says while it runs |
| The run's own name or mark | Only on a routine that runs one at a time |

A run started from **Something new…** counts exactly one thing: whether the routine it made is worth keeping.

## What it never counts

- **Check-ins.** A question about today has nothing in it for the next run.
- **A step taken out with Not in this run.** That already is an answer about today.
- **A round itself**, or its own name and number. A change you make to a round is counted.
- **Values that came with the run** when an event from somewhere else started it.
- **What arrives in a list that stays open**, such as Inbox or To read.
- **Anything already answered** with Keep or Only here.
- **Anything, once the routine is archived.** There is nothing left to keep it into.

## Where you see it

- As the band under the title bar, on the run's page, its steps' pages and its list of steps.
- In **Runs**, as a number on the corner of the run's mark.
- In the filter at the top left of **Runs**, as **Waiting on you**.

## Bringing it to nought

Press **Review** on the band. Everything it counts is listed there, wherever in the run it is, with **Keep** and **Only here** on each. See [Keep or Only here](keep-or-only-here.md).

## When something goes wrong

- **The number went up and you wrote nothing.** Some presses change the run's own settings. **Quiet this run** on a notification, for example, changes what this run says while it runs. Answer it **Only here**.
- **An old run lost its band with things still in it.** Its routine was archived. Take the routine out of the archive to answer them.
