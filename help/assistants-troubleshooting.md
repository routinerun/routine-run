# When asking an AI goes wrong

**I pressed Write it and nothing happened.**
The writer beside it needs the Routine Run Ask shortcut and it is not installed. The page
should offer **Get Routine Run Ask**. If it did not, choose **On this phone** (or **Apple's
cloud** on iOS 27) and try again.

**Shortcuts opened and closed, and nothing came back.**
Open Shortcuts and run Routine Run Ask by hand. If it stops at Use Model, the model is not
available: for ChatGPT, turn on the extension under Settings → Apple Intelligence & Siri.

**It says "Asking … in the background" for a long time.**
The bridge automation is off or asks before running. In Shortcuts → Automation, open it
and set it to run immediately. **Cancel** takes the question back.

**The answer came back but shows an orange sentence.**
The model wrote something the app cannot read. Tap **Copy this for your assistant**, paste
it back to the assistant, and paste its new answer.

**On this phone is not in the list.**
Apple Intelligence is off, still downloading, or not available on this iPhone or in this
language. It is only offered for new routines.

**Apple's cloud says it is used up.**
Apple's daily limit is reached. The page says when it comes back. Choose another writer
beside Write it until then.

**Only one step got the time I asked for.**
Say it about the whole routine: "all done by 8:30". The app asks the model to give every
step a time when you give the routine one.
